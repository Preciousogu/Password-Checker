    Spot the difference

    Weak vs. strong passwords

    Length beats complexity. A long, random phrase is far harder to crack than a short word with symbols.

    ✗ Easy to crack

    • password1 One of the most leaked passwords
    • qwerty123 Keyboard pattern + numbers
    • Sarah1997! Name + birth year
    • aaaa1111 Repeated characters

    ✓ Hard to crack

    • Maple-River-Jacket-42 Random words, long
    • t7#Kq!m2Vz9@Lp Random, 14+ characters

    Protect yourself

    6 habits that keep your accounts safe

    A strong password is the start. These habits close the gaps attackers use most.

    📏

    Go long

    Use at least 12 characters, ideally 16 or more. A passphrase of four random words is long and easy to remember.

    🔑

    One account, one password

    Never reuse passwords. If one site is breached, attackers try the same login everywhere else.

    🗄️

    Use a password manager

    Let a password manager create and remember unique passwords for you. You only need one strong master password.

    📱

    Turn on two-factor (2FA)

    Add an authenticator app or security key. Even if your password leaks, an attacker still can't get in.

    🎣

    Watch for phishing

    Don't enter your password from a link in an email or text. Go to the site directly and check the address.

    🔄

    Act fast after a breach

    If a service you use is breached, change that password right away, plus anywhere you used the same one.

    Got hacked?

    What to do if your password was leaked

    Change the password now

    Start with your email account, since it can reset every other password.

    Change it everywhere you reused it

    Give each account its own new, unique password.

    Turn on two-factor authentication

    Prefer an authenticator app or security key over text messages.

    Check recent activity

    Look for unknown logins, devices, forwarding rules or payments, and sign out other sessions.

    Watch your financial accounts

    Set up alerts with your bank and consider a credit freeze if personal details were exposed.

    FAQ

    Common questions

    Is it safe to type my password here?

    Yes. The strength and reuse checks run entirely in your browser. For the breach check, your password is turned into a hash and only the first 5 characters of that hash are sent to Have I Been Pwned, so your actual password never leaves your device. Nothing is stored.

    How does the breach check work?

    It uses Have I Been Pwned's "k-anonymity" method. The service returns every leaked hash that starts with the same 5 characters, and your browser checks for a match locally.

    What is entropy?

    Entropy estimates how unpredictable a password is, measured in bits. Each extra bit doubles the number of guesses needed. Aim for 70 bits or more.

    What makes a password strong?

    Length, randomness and uniqueness. Use 12–16+ characters, avoid names, dates and keyboard patterns, and never use the same password on two sites.

    Should I change my passwords regularly?

    Current guidance says no, not on a schedule. Change a password when there's a reason, such as a breach, and focus on making each one long and unique.
